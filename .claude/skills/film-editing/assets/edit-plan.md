## Source and timeline ledger

| Shot / source file and version | Source in | Source out | Sequence in | Sequence out | Video transition / overlap | Audio range and treatment |
|---|---|---|---|---|---|---|
| | | | | | | |

- State whether out points are exclusive and whether values are seconds or `HH:MM:SS:FF`; record frame rate for frame notation.
- Check runtime from the actual timeline, including overlaps, gaps, black and end cards. Do not blindly add source durations or assume every transition shortens the film.
- Count simultaneous picture, speech and action only once in runtime. Preserve lip-sync when making split edits.
- Distinguish extra source handles from holds that must appear in the final edit. Do not automatically duplicate incoming and outgoing settling time.

## Generation handoff, when needed

```text
OUTGOING SHOT [ID]: [frame, action phase, eyeline, props, emotion, camera motion]
INCOMING SHOT [ID]: [new frame and information; compatible state]
PICTURE CUT: [time or action/response cue]
AUDIO: [speaker, exact line, start/end relative to picture; ambience]
HANDLES: [required still or moving material before/after cut]
CONTINUITY: [selected references and visible/offscreen states]
FALLBACK: [existing coverage or simpler edit preserving the dramatic purpose]
```

Use only supported provider controls. Requested editorial timing is not a guarantee about the output. Keep approved dialogue and necessary action intact.

## Review

- Does each new shot change information, attention or feeling? Would staying longer work better?
- Are the action phase, eyeline, geography, light and emotional momentum coherent?
- Is a time jump or stylistic discontinuity intentional and readable?
- Are J/L timing and speaker binding correct, with no repeated or clipped words?
- Do transitions have usable handles, without freeze artifacts or double images?
- Does the final file preserve intended sync, cadence, resolution and runtime?
- Record playback with sound, join checks, material defects and unresolved checks in the [take/sequence review](take-review.md). Name what was actually viewed or heard.
